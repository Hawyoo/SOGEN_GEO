# SOGEN 数据集检索工具 · 使用说明

> 版本 v1.2.1（2026-07）

> 给群里老师看的教程。一句话：**在您存放 SOGEN 数据文件的文件夹里，用大白话问 AI——
> 找数据集、看详情、聊课题，它只查您手里已有的文件，答完指认到具体哪个文件。**

---

## 一、一次性准备（只做一次，约 5 分钟）

### 第 1 步：确认 Claude Code 已装好

能打开 Claude 就是装好了；还没有的话，加群主微信 bioinformaticsboy 协助安装。

> 检索工具运行还需要 Python——**这个不用您操心**：第一次提问时 AI 会自动检测，
> 缺了会自动帮您安装（中途若弹出系统授权窗口，点"是"即可；装一次，以后都不用管）。
> 想提前自己装好也可以：到 python.org 下载安装包，安装时勾选 "Add Python to PATH"；
> macOS 系统自带，无需操作。

### 第 2 步：建一个数据文件夹，把群文件放进去

把您在群里陆续下载的 `SOGEN_XXX.json` 文件放进一个文件夹（比如桌面新建"SOGEN数据"）。
- 怎么放都行：全部平铺、自己建子文件夹分类、多个群的文件混在一起，**都认**。
- **群里下载的是压缩包（.7z/.zip）也不用自己解压**——直接丢进这个文件夹，
  第一次提问时它会自动识别、就地解开再建索引（自己手动解压过也不会重复计算）。
- 以后新下载的文件，直接丢进这个文件夹就行，**不用做任何别的操作**。

### 第 3 步：把检索工具放进去

您收到的 `SOGEN-GEO` 文件夹（里面有 `SKILL.md`、`search_datasets.py` 等几个文件），
整个复制到下面这个位置（二选一）：

- **方案 A（推荐，一次装好、所有文件夹通用）**：放进您电脑的"用户目录"下的
  `.claude/skills/` 里——
  - Windows：`C:\Users\您的用户名\.claude\skills\SOGEN-GEO`
  - macOS/Linux：`~/.claude/skills/SOGEN-GEO`
- **方案 B（只在某个数据文件夹里生效）**：放进 `数据文件夹\.claude\skills\SOGEN-GEO`。

放好后路径里应该是这样： `...\.claude\skills\SOGEN-GEO\SKILL.md`（注意不是多套了一层文件夹）。

## 二、每次怎么用（10 秒上手）

1. 用 Claude Code **打开您的数据文件夹**（就是在第 2 步建的那个）。
2. 直接用大白话问。第一次问的时候会等几秒到一两分钟（它在给您的文件建索引，
   只建一次；之后每次都快），看到"索引已同步"字样是正常现象。
3. 它答完会告诉您：**哪个 GSE 数据集、在您手里哪个文件里、样本量多少、什么测序类型**——
   而且每次答完都会**推荐几个下一步可以问的问题**，觉得哪个有意思，照着问就行。

## 三、可以直接抄的问法

**第一次用？就照抄这三句（保证成功）：**

1. 「看看我手里都有什么数据」——它会给您盘点家底，并推荐接下来问什么
2. 从它推荐的里面挑一句，照着问（比如「乳腺癌有哪些数据？」）
3. 再问一句「给我详细讲讲这里面样本量最大的那个数据集」

三句问完，您就会了。以后想问什么直接说，说不清楚它也会引导您。

**一段真实的追问长这样：**

> 您：看看我手里都有什么数据
> 它：您手里有 X 个病种、Y 条数据，主要是……您可以接着问：「乳腺癌有哪些数据？」
> 您：乳腺癌有哪些数据？
> 它：有 N 条，转录组测序最多……推荐您看看 GSE96058（3409 例大队列）。您可以接着问：
> 「GSE96058 详细讲讲」或「这些里面哪些带生存分析？」
> 您：这些里面哪些带生存分析？
> 它：……

**看看自己都有什么：**
- 「看看我手里都有什么数据」
- 「我这个文件夹里有多少个病、多少条数据？」

**找数据集：**
- 「有没有关于肺动脉高压的数据集？」
- 「帮我找乳腺癌里样本量大于 100 的单细胞数据」
- 「有没有小鼠的肺纤维化模型数据？」（说"小鼠"就行，不用记学名）
- 「GSE96058 这个数据集详细给我讲讲」

**聊课题（从临床问题出发）：**
- 「我是看 XX 病的，临床上想解决 XX 问题（比如术后复发风险怎么分层 / 哪类患者对
  XX 药敏感 / 有没有能早诊的标志物），帮我看看手里的数据能不能支撑这个课题」
- 它会先和您确认临床问题，再用真实数据告诉您：有哪些数据可用、设计合不合理、
  具体在您哪个文件里。

**了解 SOGEN：**
- 「SOGEN 是干什么的？」「除了数据你们还能帮我做什么？」——它会介绍业务，
  完整版也可以打开随包的《SOGEN介绍.md》看。

## 四、常见问题

- **不知道能问什么** → 直接说「看看我手里都有什么数据」，它会盘点家底并推荐下一步，
  跟着它的推荐问就行。
- **刚在群里下载了新文件** → 丢进数据文件夹就行，下次提问自动纳入，不用任何操作。
- **下载的是压缩包，还没解压** → 不用解压，丢进数据文件夹就行；它会在下次提问时
  自动解开（.zip 直接解；.7z 如果没装解压工具，它会提示并自动帮您装一个，或您自己
  双击解压也一样）。压缩包和已解压的文件同时存在，也不会重复计算。
- **它提示某个压缩包"无法读取/可能损坏"** → 多半是下载中断了，把那个包重新下载一份
  丢进文件夹再问即可。
- **它说"正在帮您安装 Python"** → 正常现象，运行检索需要；装一次以后都不用管。
  中途弹出系统授权窗口点"是"。
- **搜不到某个病** → 先确认那个病的 JSON 文件确实在这个文件夹里（注意：只下载了
  Excel 不算，要以 `SOGEN_..._01_...json` 这类 JSON 文件为准，Excel 内容一样不重复计）。
  确认文件在还搜不到，就是这个病还没发到群里——加群主微信 bioinformaticsboy 问。
- **换了文件夹** → 没关系，每个文件夹独立建索引，互不影响。
- **数据安全** → 这个工具只读您本地文件，没有任何联网行为，您的文件不会上传。
- **它提到"专题精选 JSON 不索引"** → 正常的，专题文件内容和 7 个分类 JSON 重叠，
  不重复计算，不影响结果完整性。
